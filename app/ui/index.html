Insights

A local model reads your jobs' logs and your agents' transcripts, then writes a short note on each. It runs on Ollama, on this Mac by default.

Saved to config.toml
Write insights
Summarise running jobs and active agents on Home, in each row and in the menu bar.
Model
Any chat model from ollama list. Small general models (Gemma, Llama, Qwen) work well.
Read job logs
Include the last lines of each running job's log (one extra SSH round trip per job).

No Ollama yet? Install it from ollama.com, then run ollama pull gemma3.

Applies immediately
Icon messages
The floating icon shows a message (close it with ✕) when these happen.

macOS notifications are sent for finished and failed jobs, agents waiting for you, limits above the threshold, and problems an insight newly flags (when Insights is on). Manage them in System Settings → Notifications → Vixen.
